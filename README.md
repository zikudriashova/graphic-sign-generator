# Генератор знаков / Sign Generator

Интерактивный тул для создания графических знаков в квадрате по модульной сетке.
Все части знака (четыре конечности и голова) растут из одной точки.

*An interactive tool for making graphic signs on a square modular grid. Every part (four limbs and a head) grows from a single point.*

## Как пользоваться

Откройте `index.html` в браузере. Сборки и зависимостей нет: это один файл с HTML, CSS и JavaScript.
Шрифты подгружаются с Google Fonts, без интернета страница работает на системных шрифтах.

## Параметры

| Параметр | Что делает |
|---|---|
| **Толщина лучей** | от тонких до толстых конечностей |
| **Форма линии** | от простой линии одной толщины до лопасти с утолщением на конце |
| **Пластика** | от строгой геометрии до плавных, сливающихся форм |
| **Голова** | капля, полумесяц или сектор; толщина головы настраивается отдельно |
| **Поза** | генератор по номеру: один номер всегда даёт одну и ту же композицию; кнопки «←», «→», «Случайная» |
| **Зеркально**, **Закрутка** | отражение и направление изгиба лучей (единая, обратная, смешанная) |
| **Сетка** | 4, 6, 8 или 12 модулей по стороне; концы лучей всегда попадают в узлы сетки |
| **Цвет** | пресеты и свободный выбор цвета фона и знака |
| **Экспорт** | SVG и PNG |

## Правила генератора поз

- ровно пять лучей: голова и четыре конечности;
- голова смотрит вверх и короче конечностей, ноги идут вниз, руки в стороны или вверх;
- лучи не ближе ~36° друг к другу, а композиция сбалансирована вокруг центра;
- конец каждого луча срезается ровно по линии сетки.

## Как это устроено

Каждая часть знака описывается расстоянием до формы (signed distance field). Части плавно объединяются,
и контур снова превращается в векторный путь (marching squares, упрощение, сглаживание кривыми),
поэтому экспортный SVG состоит из чистых путей.
